# Echte Screenshots ergänzen

Der README enthält zunächst einen **klar gekennzeichneten Platzhalter**. Nach dem ersten Pages-Deployment:

1. Öffne die Live-Demo bei ungefähr 1440 px Browserbreite.
2. Nutze Beispielwerte, etwa 500 € Kaufpreis, Zustand „Gut“, Alter 2 Jahre. Es sind fiktive Eingaben, keine beobachteten Verkäufe.
3. Erstelle einen Screenshot ohne Browserdaten, persönliche Informationen oder fremde Kleinanzeigen.
4. Speichere ihn als `docs/toolkit-desktop.png` und ersetze den Platzhalter-Link im README.
5. Prüfe zusätzlich die mobile Ansicht bei ungefähr 390 px Breite. Optional als `docs/toolkit-mobile.png` ergänzen.

Keine Screenshots der AnzeigenBoost-Oberfläche als Screenshot dieses Toolkits ausgeben.
