# Mitmachen

Danke für dein Interesse. Halte Beiträge klein, nachvollziehbar und für Verkäufer nützlich.

1. Erstelle ein Issue mit Problem, Beispiel und gewünschtem Verhalten.
2. Forke das Repository, erstelle einen Branch und ändere nur den betroffenen Bereich.
3. Führe `npm test` und `npm run build` aus.
4. Eröffne einen Pull Request mit kurzer Beschreibung und Screenshot bei UI-Änderungen.

Für Preisregeln: Erkläre jede neue Annahme in der Oberfläche und in den Tests. Behaupte keine Marktgenauigkeit ohne belastbare Daten. Füge keine Käufernachrichten, persönlichen Daten, Scraper, Tracking-Skripte oder proprietären AnzeigenBoost-Code hinzu. Vorlagen dürfen keine ungeprüften Tatsachen über Versand, Zustand oder Zahlung behaupten.
